Open-space counts for Santa Barbara Airport's three public lots, as plain JSON. No key, no sign-up. Every response is a flat list of flat rows.

You're building something that reads the SBA Parking API: live open-space counts for Santa Barbara Airport's three public parking lots. Full docs: https://around805.com/sba-parking/api.html

Endpoints (no key, CORS open, JSON):

GET https://around805.com/sba-parking/api/v1/latest
  Array, one row per lot:
  lotId (string, stable key), lot (short name), total (number), open (number),
  percentFull (0-100), status ("Open" | "Limited" | "Full"),
  updatedAt (ISO 8601 UTC, when the airport published it)

GET https://around805.com/sba-parking/api/v1/hourly?date=YYYY-MM-DD
  Array of 72 rows, 24 Pacific hours x 3 lots, hourly averages:
  date, hour (0-23 Pacific), lotId, lot, total,
  open (number or null), percentFull (number or null)
  date defaults to today in Pacific time. History starts 2026-09-09.

Rules:
- Key lots by lotId, not by name.
- null means no fresh count that hour (future hour, or the airport's feed paused). Show it as missing. Never fill it in.
- Data changes about every 5 minutes. Poll /latest at most once a minute.
- On a non-200 response, keep showing the last good data and retry later.
- Times in /hourly are Pacific; updatedAt is UTC.

What I want built:

How fresh is it

The airport publishes new counts about every 3 minutes, and this tracker checks every 5, so data updates about every 5 minutes. Responses are also reused for up to 2 minutes (latest) or 5 minutes (hourly), so polling more than once a minute gets you nothing new. Please don't.

GET /latest

Current count for each lot. One row per lot.

[
  {"lotId": "2", "lot": "Economy", "total": 564, "open": 68, "percentFull": 88, "status": "Limited", "updatedAt": "2026-11-27T07:03:00Z"},
  {"lotId": "3", "lot": "Short-term", "total": 192, "open": 11, "percentFull": 94, "status": "Limited", "updatedAt": "2026-11-27T07:03:00Z"},
  {"lotId": "4", "lot": "Long-term", "total": 780, "open": 28, "percentFull": 96, "status": "Limited", "updatedAt": "2026-11-27T07:03:00Z"}
]
fieldtypemeaning
lotIdstringThe airport's own lot ID. Use this as the key; it stays put if a lot is renamed.
lotstringShort lot name: Economy, Short-term, Long-term.
totalnumberSpaces in the lot, excluding ADA spaces.
opennumberSpaces free right now.
percentFullnumber0 to 100, whole number.
statusstringOpen (under 75% full), Limited (75 to 99%), Full (100%). Same thresholds as the airport's site.
updatedAtstringWhen the airport published this count, ISO 8601 in UTC.

GET /hourly?date=YYYY-MM-DD

One row per lot per hour for one day, averaged over that hour. date is a Pacific calendar day and defaults to today. Hours run 0 to 23 in Pacific time. A day is always 72 rows (24 hours × 3 lots), including hours that haven't happened yet.

[
  {"date": "2026-11-26", "hour": 0, "lotId": "2", "lot": "Economy", "total": 564, "open": null, "percentFull": null},
  {"date": "2026-11-26", "hour": 0, "lotId": "3", "lot": "Short-term", "total": 192, "open": null, "percentFull": null},
  ...
  {"date": "2026-11-26", "hour": 23, "lotId": "3", "lot": "Short-term", "total": 192, "open": 11, "percentFull": 94}
]
fieldtypemeaning
datestringThe Pacific calendar day asked for.
hournumber0 to 23, Pacific.
lotId, lot, totalSame as /latest.
opennumber or nullAverage free spaces that hour.
percentFullnumber or nullAverage percent full that hour.

null means no fresh count that hour: it hasn't happened yet, the airport paused its feed (it sometimes stops publishing overnight or for days at a time), or the tracker wasn't running. A null is never filled in with a guess. History starts 2026-09-09.

Examples

curl https://around805.com/sba-parking/api/v1/latest

curl 'https://around805.com/sba-parking/api/v1/hourly?date=2026-11-20'
const res = await fetch('https://around805.com/sba-parking/api/v1/latest')
if (!res.ok) throw new Error(`HTTP ${res.status}`)
const lots = await res.json()
const shortTerm = lots.find((l) => l.lotId === '3')

Browser JavaScript on any site can call these directly; responses carry Access-Control-Allow-Origin: *.

Errors

A bad date returns 400 with {"error": "..."}. An unknown path returns 404. A 503 means the database hit its daily limit; data comes back after midnight UTC. Anything else is a 500; try again in a few minutes.

Stability

Fields in v1 won't be renamed or removed, and their meaning won't change. New fields may be added, so ignore ones you don't know. Anything breaking would ship as v2 alongside this one. The page's own /api/ routes (without v1) are internal and change without notice.

Where it comes from

Counts come from the airport's own feed at flysba.santabarbaraca.gov. This is an independent tracker, not an airport service.
